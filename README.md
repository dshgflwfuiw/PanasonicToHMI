# 松下 PLC 变量转 HMI 工具

将松下 Control FPWIN Pro 7 导出的 CSV 变量文件转换为多种品牌 HMI 可用格式。

## 功能特性

- ✅ **多品牌支持**: 威纶通、西门子、三菱、欧姆龙、台达
- ✅ **进度条显示**: 实时显示处理进度
- ✅ **错误行导出**: 自动收集并导出格式错误的行
- ✅ **拖拽优化**: 支持拖拽文件，带视觉反馈
- ✅ **多编码检测**: 自动识别 UTF-8/GBK/ASCII 等编码
- ✅ **彩色日志**: 不同级别日志区分显示

## 快速开始

### 本地运行
```bash
dotnet run
```

### GitHub Actions
项目已配置 CI/CD，每次 push 或 PR 会自动：
- 编译构建
- 运行单元测试
- 验证多品牌转换逻辑

## 支持的品牌模板

| 品牌 | X 地址前缀 | Y 地址前缀 | D 地址前缀 |
|------|-----------|-----------|-----------|
| 威纶通 | LB | LW | LW |
| 西门子 | I | Q | DB |
| 三菱 | X | Y | D |
| 欧姆龙 | 位地址 | 字地址 | 字地址 |
| 台达 | X | Y | D |
